### [PRRegression Audit: RL Environment & Multi-Agent Code Reviewer](https://github.com/SAISANJAYR/GitPRTriageEnv)

PR descriptions always describe the intended feature, never the flaw. This environment trains LLM agents to act as senior reviewers that catch the regressions hiding inside pull requests. **Finalist at the OpenEnv Hackathon** (Bengaluru).

</div>

- 🧩 Autonomous **4-agent pipeline** (Safety → Defect → Router → Comment) backed by FastAPI and Docker
- ✅ Deterministic programmatic grading (**RLVR**) so the agent can't reward-hack
- 📈 **2.1× reward gain** on Medium tasks by fine-tuning **Qwen2.5-1.5B with GRPO**
- 📊 Live **Weights & Biases** dashboard, hosted on [Hugging Face Spaces](https://huggingface.co/spaces/rsd-06/PRRegressionAuditEnv)
